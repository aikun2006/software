## 大字版导航栏文字溢出 + 按钮重叠修复

### 导航栏文字溢出修复
- **根因**：`.uni-tabbar__item` 和 `.uni-tabbar__bd` 使用 `display:flex` + `flex-direction:column`，flex 容器会尝试撑开适应内容而非约束它
- **修复**：改为 `display:block` + `height:50px` + `overflow:hidden`，文字通过 `.uni-tabbar__label` 的 `display:block` + `text-align:center` + `line-height:50px` 居中
- **影响**：中文大字模式和英文大字模式两套样式同步修改

### 按钮重叠修复
- **根因**：大字模式下 `.font-toggle-btn` 和 `.lang-toggle-btn` 施加 `transform:scale(1.2)` + `transform-origin:right center`，视觉向左膨胀20%导致重叠
- **修复**：移除两个按钮的 `transform:scale(1.2)` 和 `transform-origin`（文字已通过 `font-size:calc(1em+8px)` 放大，scale 多余）；保留 `min-width:140rpx` + `padding:0 28rpx`
- **位置调整**：`.lang-toggle-btn` 的 `right` 从 `400rpx` → `460rpx`，增加与大字版按钮间距
