## 二、各方案详细实施记录

### D1: 口型同步精度提升

#### 实施步骤

1. **ttsEngine.ts 改造**
   - 新增 `AnalyserNode` 成员变量，`fftSize=512`（256 个频率分箱），`smoothingTimeConstant=0.6`
   - 新增 `ensureContext()` 懒创建方法：首次播放时同时创建 AudioContext 和 AnalyserNode，analyser 常驻连接到 `destination`
   - 修改 `playAudio()` 中音频管线：`source.connect(analyser)` → `analyser.connect(destination)`（原有直连 destination 改为经 analyser 中转）
   - 暴露 `getAnalyser(): AnalyserNode | null` 和 `isAudioPlaying(): boolean` 两个公开方法

2. **Avatar3D.vue 频谱驱动视素**
   - 新增 `updateMouthFromAudio()` 函数：从 AnalyserNode 提取 `getByteFrequencyData`，按频段映射到 5 个 VRM 视素
   - 频段划分：低频（0~516Hz）→ `aa/oh/ou`（开口/圆唇），中频（516Hz~2.1kHz）→ `ee`（扁唇），中高频 → `ih`
   - 静音检测：总能量 < 0.05 时所有视素归零，避免背景底噪驱动口型
   - 增益系数 1.3 + `Math.min(1, ...)` 确保权重不越界

3. **停止时机优化**
   - 新增 `textEnded` 标志：`speakText()` 文本念完时仅标记 `textEnded=true`，不立即 `stopSpeaking()`
   - animate 循环中判断：`textEnded && !audioDriving` 时才真正停止，避免 TTS 音频比文本更长时口型提前收口

#### 预期成果 vs 实际效果

| 指标 | 预期 | 实际 |
|------|------|------|
| 口型驱动方式 | 文本字符定时 → 音频频谱实时 | ✅ 频谱优先，文本回退 |
| 视素精度 | 5 个视素独立控制 | ✅ aa/ih/ou/ee/oh 独立映射 |
| 音视频同步 | 嘴型与 TTS 音频同步 | ✅ AnalyserNode 实时读取频域 |
| 回退机制 | 无音频时用文本驱动 | ✅ `updateMouthFromAudio()` 返回 false 时文本驱动接管 |

### D5: 数字人形象管理增强

#### 实施步骤

1. **后端（server.py）**
   - 新增 `avatars` 表：id/name/vrm_path/voice_type/model_scale/position_x/position_y/rotation_y/is_active/file_size
   - `_init_avatars()` 初始化默认形象（小乐，使用内置 use_for_app1.vrm）
   - 新增 19 种 Edge-TTS 音色列表（晓晓/云希/云扬/晓辰等）

     - `GET /api/admin/avatars` — 列表
     - `GET /api/admin/avatars/voices` — 音色列表
     - `GET /api/avatars/active` — 公开获取当前启用形象
     - `POST /api/admin/avatars/upload` — VRM 文件上传（multipart，100MB 上限）
     - `POST /api/admin/avatars/create` — 新建
     - `POST /api/admin/avatars/update` — 编辑
     - `POST /api/admin/avatars/delete` — 删除（含文件清理）
     - `POST /api/admin/avatars/activate` — 启用
     - `POST /api/admin/tts/preview` — TTS 音色试听
   - `synthesize_tts()` 改为从数据库读取当前启用数字人的音色配置
   - 新增 `_parse_multipart()` 简易 multipart/form-data 解析器

2. **管理后台（avatar.vue）**
   - 完整重写：移除 mock 数据，全部使用真实 API
   - VRM 文件上传：`XMLHttpRequest` + `FormData` + 上传进度显示
   - 音色选择：picker 组件 + 19 种 edge-tts 音色
   - TTS 试听：`POST /api/admin/tts/preview` → blob → Audio 播放
   - 模型参数配置：缩放（1~5）、朝向旋转（-π~π）、水平/垂直偏移（-1~1）滑块
   - 3D 实时预览：弹窗内嵌 Avatar3D 组件，支持旋转/缩放查看
   - 列表卡片展示：名称、文件大小、VRM 路径、音色、缩放、朝向

3. **Avatar3D.vue 组件增强**
   - 新增 props：`modelPath`、`modelScale`、`modelRotationY`
   - `initScene()` 中从 props 读取模型路径和缩放
   - 新增 `reloadModel(modelPath)` 函数：清除旧模型 → 加载新 VRM → 重新计算相机距离
   - 新增 3 个 `watch`：modelPath 变化触发重载，modelScale/modelRotationY 变化实时更新

4. **游客端（chat.vue）**
   - `onMounted` 中 `fetch('/api/avatars/active')` 获取当前启用形象
   - 将 `vrm_path/model_scale/rotation_y` 传递给 Avatar3D 组件
